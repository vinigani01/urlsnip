// Features

Everything you need,
nothing you don't.

01

Custom Aliases

Choose your own short code — /my-project, /docs, anything you want instead of a random string.

02

Click Tracking

Every redirect is counted. See how many times each link has been clicked from the built-in dashboard.

03

Persistent Storage

Links are stored in SQLite and survive container restarts via Docker volumes. No external database needed.

04

Any URL

Works with any valid web URL. Automatically prepends https:// if the protocol is missing.

05

Public Access

Expose your instance publicly via Cloudflare Tunnel or ngrok. Set BASE_URL and your links work everywhere.

06

Zero Dependencies

No external services, no cloud accounts required. One docker compose up and you're running.

// Tech Stack

Built with modern,
battle-tested tools.

⬡
Node.js + Express
Lightweight REST API server handling shortening, redirects, and stats
◫
SQLite (better-sqlite3)
Embedded database — zero config, fast, file-based persistence
◳
Docker + Compose
Fully containerised — one command deploy on any machine or server
◈
Vanilla HTML/CSS/JS
No frontend framework — fast, dependency-free, served directly by Express
// How it works

Up and running
in minutes.

01

Clone the repo

Download the project from GitHub onto your machine or server.

02

Set BASE_URL

Point BASE_URL to your domain or tunnel URL so generated links are correct.

03

docker compose up

One command builds the image, starts the container, and creates the data volume.

04

Start shortening

Open the app in your browser, paste a URL, and get a short link instantly.

# deploy with a public URL BASE_URL=https://your-domain.com docker compose up --build -d # or with ngrok for quick testing ngrok http 3000 BASE_URL=https://xxxx.ngrok-free.app docker compose up -d
